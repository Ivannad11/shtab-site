# Сайт ШТАБ

`index.html` — весь сайт одним файлом, фото в `img/`, презентация в `files/`.
Открывается локально: `python3 -m http.server` в этой папке.

Структура блоков собрана по референсу **u24.services**, визуальный язык — свой:
синий `#001AFF`, скруглённые плитки, мозаика направлений и цифр, светлые и тёмные секции вперемешку.

## Страницы и адреса

Сайт одностраничный, страницы переключаются хэшем — адрес можно скопировать и переслать,
кнопка «назад» в браузере работает:

| Адрес | Страница |
|---|---|
| `/` | Главная |
| `#cases` | Проекты |
| `#case/02` | Карточка проекта (номер — поле `n` в `CASES`) |
| `#services` | Услуги |
| `#about` | Команда |
| `#contacts` | Контакты |

Неизвестный хэш уводит на главную, несуществующий номер проекта — в список проектов.

## Заявка

Форма на странице контактов — только имя и телефон, рядом кнопка «Позвонить».
Проверка: имя от 2 символов, телефон от 10 цифр. Доставка настраивается одним объектом:

```js
var FORM = { mode: 'none', token: '', chat: '', endpoint: '' };
```

- `none` — канала нет: форма выключена и честно пишет «Заявки пока не принимаем» (текущее состояние)
- `telegram` — `token` бота и `chat` (chat_id), бот пишет в чат
- `formspree` — `endpoint` вида `https://formspree.io/f/xxxxxxx`
- `mailto` — открывает почтовый клиент на `CONTACTS.mail`

Форма включается сама, как только канал настроен: `telegram` с токеном и чатом,
`formspree` с endpoint или `mailto` при настоящей почте. Пока канала нет, сайт не
делает вид, что заявка ушла, — это единственное честное поведение на живом адресе.

## Два замка до согласования

Пока в `CONTACTS` стоят плейсхолдеры, а в `FORM` нет канала:

1. **Почта и телефон не показываются** — вместо них «появится после согласования»,
   ссылок `mailto:` и `tel:` нет. Раньше `hello@example.ru` уходил живой ссылкой
   в контакты, футер и мобильное меню.
2. **Сайт закрыт от поиска** — `<meta name="robots" content="noindex, nofollow">`.

Оба замка снимаются сами, руками ничего править не нужно: впишите настоящие почту
с телефоном в `CONTACTS` и канал в `FORM` — форма включится, `noindex` пропадёт.

## Что заменить перед публикацией

1. **Контакты** — вверху скрипта:
   ```js
   var CONTACTS = { mail: 'hello@example.ru', phone: '+7 XXX XXX-XX-XX' };
   ```
   Расходятся сразу в контакты, футер и мобильное меню, включая разделение
   «госзаказчикам / корпоративным». Пока в `phone` меньше 10 цифр, сайт не делает
   ссылку `tel:` и вместо кнопки «Позвонить» показывает «Телефон появится после
   согласования» — как только впишете настоящий номер, кнопка заработает сама.
2. **Шоурил**: `var SHOWREEL = { src: 'img/showreel.mp4', poster: 'img/showreel.jpg' }`.
   Пока пусто — стоит градиентная заглушка. Формат: mp4 без звука, 15—40 секунд, зациклено.
3. **Галерея «С площадок»**: массив `GALLERY`, сетка растёт сама, пропорции 3:2.
3a. **Благодарственные письма**: сканы в `img/letters/`, путь — в массив `LETTERS`:
   ```js
   { org: 'АНО «Таврида.Арт»', note: 'арт-школа продюсирования ИИ', img: 'img/letters/tavrida.jpg' }
   ```
   Пока `img` пустой — карточка показывает заглушку с названием организации.
4. **Фото проектов** — у каждого кейса свой массив `photos`, из него собирается
   галерея на странице проекта, а первый кадр идёт обложкой карточки в списке:
   ```js
   photos: [
     { src: 'img/gorky-1.jpg', cap: 'Деловой блок форума' },
     { src: 'img/gorky-2.jpg', cap: 'Регистрация участников' }
   ]
   ```
   Плитки 280×187, по клику фото открывается во весь экран — листается стрелками
   на экране и на клавиатуре, закрывается Esc или кликом мимо снимка.
   Пустой массив — блока с фотографиями нет, карточка держится на крупной метрике.
   Сейчас снимки есть у двух кейсов из семи, по одному на каждый.
   Галерея «Работа на площадке» на главной (`GALLERY`) открывается тем же просмотрщиком.
5. **Кейс «Газпром недра»** — публикация требует согласия заказчика (файл 50 §7).
6. **Фото команды** — плашка Катерины пока с инициалом вместо портрета.
7. **Картинка для соцсетей** — `og:image` временно ведёт на `img/case-gorky.jpg`.

## Открытые вопросы

- Согласие партнёров на кейсы Метафоры — без него ЦИК, Сбер, ПМЭФ, ЦСКА, ВДНХ на сайт не идут.
- Срок «3 дня» подтверждён только для событий, для мультимедиа не проверен.
- Производство реально идёт через партнёров — на сайте этого больше нет,
  но на переговорах вопрос «кто в штате» прозвучит, ответ нужно заготовить.
