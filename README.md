# Сайт ШТАБ

Исходник один — `src/index.html`. Из него `python3 build.py` собирает 12 настоящих адресов
в корне репозитория плюс `sitemap.xml`. Фото в `img/`, презентация в `files/`.

**Правки вносить только в `src/`, потом пересобирать.** Файлы в корне (`index.html`,
`cases/`, `services/` и остальные) — результат сборки, руками их не трогают: следующий
`build.py` перезапишет.

Сборщик поднимает локальный сервер, открывает исходник в headless Chrome по каждому
хэшу, забирает готовую разметку, вырезает чужие секции и вставляет свои мета и JSON-LD.
Логика рендера не дублируется — она одна, в `src/`.

Адрес сайта задан двумя константами в начале `build.py`:

```python
SITE = 'https://ivannad11.github.io'
BASE = '/shtab-site'          # на своём домене: BASE = ''
```

Смотреть локально нужно по тому же пути, иначе ссылки вида `/shtab-site/...` не найдутся:

```sh
mkdir -p /tmp/serve && ln -s "$PWD" /tmp/serve/shtab-site
cd /tmp/serve && python3 -m http.server 8912
# открыть http://localhost:8912/shtab-site/
```

Структура блоков собрана по референсу **u24.services**, визуальный язык — свой:
синий `#001AFF`, скруглённые плитки, мозаика направлений и цифр, светлые и тёмные секции вперемешку.

человек попадёт на главную.

## Заявка

Форма на странице контактов — только имя и телефон, рядом кнопка «Позвонить».
Проверка: имя от 2 символов, телефон от 10 цифр, галочка согласия на обработку данных.
Галочка снята по умолчанию — согласие человек ставит сам, иначе заявка не уходит.
Доставка настраивается одним объектом:

```js
var FORM = { mode: 'mailto', token: '', chat: '', endpoint: '' };   // текущее состояние
```

- `none` — канала нет: форма выключена и честно пишет «Заявки пока не принимаем»
- `telegram` — `token` бота и `chat` (chat_id), бот пишет в чат
- `formspree` — `endpoint` вида `https://formspree.io/f/xxxxxxx`
- `mailto` — открывает почтовый клиент на `CONTACTS.mail`

Форма включается сама, как только канал настроен: `telegram` с токеном и чатом,
`formspree` с endpoint или `mailto` при настоящей почте. Пока канала нет, сайт не
делает вид, что заявка ушла, — это единственное честное поведение на живом адресе.

## Два замка до согласования — сейчас оба сняты

Замки срабатывают сами, пока в `CONTACTS` плейсхолдеры, а в `FORM` нет канала:

1. **Почта и телефон не показываются** — вместо них «появится после согласования»,
   ссылок `mailto:` и `tel:` нет.
2. **Сайт закрыт от поиска** — `<meta name="robots" content="noindex, nofollow">`.

Сейчас контакты вписаны, `FORM.mode = 'mailto'`, `PUBLISH = true` — сайт открыт для
поиска, форма работает. Чтобы снова закрыть от индексации, хватит `PUBLISH = false`
в `src/` и пересборки.

## Поиск и аналитика

Сделано: свои мета и canonical на каждой странице, OG, JSON-LD (Organization на всех,
BreadcrumbList, CreativeWork на карточках кейсов), `sitemap.xml`, `robots.txt`, `404.html`,
страница обработки ПД и согласие в форме, настоящие ссылки в навигации вместо `onclick`.

Не сделано, нужны действия руками:

- **Яндекс Метрика** — счётчика нет. Нужен новый номер (счётчик «Метафора Фотозоны»
  переиспользовать нельзя), после установки — цели `lead`, `phone`, `telegram`, `email`.
- **Яндекс Вебмастер** — подтверждение мета-тегом или HTML-файлом, потом добавить sitemap.
- **Google Search Console** — верификация HTML-файлом: домен `github.io` общий, способ
  через DNS недоступен.
