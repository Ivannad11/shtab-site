# Сайт ШТАБ

`index.html` — весь сайт одним файлом, фото в `img/`, презентация в `files/`.
Открывается локально: `python3 -m http.server` в этой папке.

Структура блоков собрана по референсу **u24.services**, визуальный язык — свой:
синий `#001AFF`, скруглённые плитки, мозаика направлений и цифр, светлые и тёмные секции вперемешку.

## Порядок блоков главной

Герой с шоурилом → бегущая лента → о компании + мозаика (направления вперемешку с цифрами) →
проекты → с площадок → услуги пилюлями → надёжность на тёмном → процесс 01–07 →
заказчики → синий CTA. Дальше — страницы «Проекты», «Услуги», «Команда», «Контакты».

## Чего на сайте нет намеренно

- Цифр Studio 911 из макета партнёра: 128 спецпроектов, 34 человека, 18 рендер-нод,
  12 000 зрителей, 24/7, 9 лет — разбор в файле 52.
- Темы субподряда: «работаем под вашим брендом», «своими силами / с партнёрами».
  Для госзаказчика это причина не выбрать. Снято по решению заказчика 10.08.
- Цен и FAQ — по решению заказчика.

## Что заменить перед публикацией

1. **Контакты** — вверху скрипта:
   ```js
   var CONTACTS = { mail: 'hello@example.ru', phone: '+7 XXX XXX-XX-XX' };
   ```
   Расходятся сразу в контакты и футер, включая разделение «госзаказчикам / корпоративным».
2. **Шоурил**: `var SHOWREEL = { src: 'img/showreel.mp4', poster: 'img/showreel.jpg' }`.
   Пока пусто — стоит градиентная заглушка. Формат: mp4 без звука, 15—40 секунд, зациклено.
3. **Галерея «С площадок»**: массив `GALLERY`, сетка растёт сама, пропорции 3:2.
3a. **Благодарственные письма**: сканы в `img/letters/`, путь — в массив `LETTERS`:
   ```js
   { org: 'АНО «Таврида.Арт»', note: 'арт-школа продюсирования ИИ', img: 'img/letters/tavrida.jpg' }
   ```
   Пока `img` пустой — карточка показывает заглушку с названием организации.
4. **Фото проектов** — сейчас есть у двух из семи, остальные держатся на крупной метрике.
5. **Кейс «Газпром недра»** — публикация требует согласия заказчика (файл 50 §7).
6. **Фото команды** — плашка Катерины пустая.

## Открытые вопросы

- Согласие партнёров на кейсы Метафоры — без него ЦИК, Сбер, ПМЭФ, ЦСКА, ВДНХ на сайт не идут.
- Срок «3 дня» подтверждён только для событий, для мультимедиа не проверен.
- Производство реально идёт через партнёров — на сайте этого больше нет,
  но на переговорах вопрос «кто в штате» прозвучит, ответ нужно заготовить.
